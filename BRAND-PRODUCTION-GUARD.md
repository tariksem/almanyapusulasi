# Almanya Pusulası — Brand Production Guard

This file is a machine/human operating contract for every AI, automation, design tool and publishing workflow that creates Almanya Pusulası branded material.

## Non-negotiable source of truth
- Read and obey `BRAND-IDENTITY.md` before creating branded output.
- Canonical logo source: `assets/brand/almanya-pusulasi-logo.png`.
- Approved scaled variants: `assets/brand/almanya-pusulasi-logo-256.png` and `assets/brand/almanya-pusulasi-logo-64.png`.
- If the canonical logo cannot be loaded exactly, STOP. Do not substitute, approximate, redraw or invent.

## AI image generation rule
AI image generation may create only:
- background photography,
- neutral illustrations,
- unbranded decorative imagery.

AI image generation MUST NOT create the final branded visual and MUST NOT:
- draw the Almanya Pusulası logo,
- imitate a compass logo,
- write a fake logo lockup,
- approximate logo geometry,
- alter logo proportions, colors or internal geometry.

The final branded composition must add the real canonical logo as a separate source asset after any AI-generated background exists.

## Approved final-composition paths
1. Deterministic renderer using the canonical repo logo.
2. Canva using the uploaded canonical repo logo as an untouched asset.
3. Manual compositing using the canonical repo logo without redraw or transformation beyond proportional scaling.

## Locked visual system
- Primary: #102A43
- Primary Light: #1F4E79
- Accent: #D89B2B
- Text: #172033
- Muted: #5F6B7A
- Background: #F6F8FB
- Surface: #FFFFFF
- Footer: #0B1220

Do not introduce a replacement primary palette.

## Social-media production gate
Before publish, all must be true:
- real canonical logo asset used,
- no AI-generated/fake logo visible anywhere,
- palette complies with brand system,
- typography is clean sans-serif, no decorative handwriting as brand language,
- no stock-advertising or tourism-poster aesthetic,
- message is decision-support oriented, not hype,
- destination URL and CTA are correct,
- final visual reviewed at mobile size.

If any check fails, the asset is rejected and must not be published.
