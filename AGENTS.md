# AGENTS.md

Mandatory repository rule for every AI agent, automation and coding assistant:

1. Read `BRAND-IDENTITY.md` and `BRAND-PRODUCTION-GUARD.md` before any branded visual, social-media asset, logo, Open Graph image, cover, poster or marketing creative work.
2. Never use image generation to render, redraw, imitate or approximate the Almanya Pusulası logo.
3. Final branded visuals must use the exact canonical file `assets/brand/almanya-pusulasi-logo.png` (or the approved 256/64 variants when size-appropriate).
4. If the canonical logo is unavailable, stop instead of substituting.
5. Run `node scripts/validate-brand-lock.js` before deploy or delivery of repository-generated branded assets.
6. Treat brand-lock CI failures as release blockers.
